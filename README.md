Description:
  This project is a Task Management program I made following the requirements and constraints from https://roadmap.sh/projects/task-tracker?fl=1. I learned a lot from this, especially dealing with the argparse library and creating a usable CLI. This was my first project doing something like this and I am very happy with how it turned out. I'm sure there are more features to add and I will attempt to document any changes.

Usability: 
  To use this program and get an idea of how it works, please type: python main.py. This will pop up a help menu that gives you a list of all available commands.
